# Stock Market Analysis Dashboard

## Project Overview
This project analyzes stock market listing data using Tableau to uncover insights related to ETFs, listing exchanges, market categories, and financial status distributions.

## Tools Used
- Excel
- Tableau Public

## Key Features
- KPI Cards for Total Listings, ETFs, and Exchanges
- Market Category Distribution Analysis
- ETF vs Non-ETF Comparison
- Listing Exchange Analysis
- Financial Status Distribution
- Interactive Dashboard Filters

## Business Insights
- Non-ETF securities dominated the listings.
- Listing distribution varied across exchanges.
- ETF representation was comparatively smaller.
- Financial status categories showed diverse market structures.
